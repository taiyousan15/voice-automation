# 音声自動化システム v2.0 - 詳細フロー設計

---

## フロー詳細

### Phase 1: グローバルリサーチ

**入力**: キーワード（例: "Claude Code"）

**実行スキル**:
1. `world-research` - 全世界から情報収集
2. `keyword-mega-extractor` - 関連キーワード抽出

**収集先**:
- SNS: X, Reddit, note.com, YouTube
- ニュース: TechCrunch, VentureBeat, 日本経済新聞
- 学術: Arxiv, Google Scholar
- ビジネス: Product Hunt, Indie Hackers
- マーケティング: HubSpot, Neil Patel Blog

**出力**:
- 100-200記事の情報
- 50-100個の関連キーワード

---

### Phase 2: 音声配信者分析（オプション）

**目的**: 人気配信者の台本構造を学習

**プロセス**:
1. stand.fmから人気配信者10人の音声をダウンロード
2. Whisper APIで文字起こし
3. Claude APIで構造分析
4. 10種類のテンプレート生成

**テンプレート例**:
- ニュースアンカー型
- ストーリーテラー型
- 解説・教育型
- VSL型
- etc.

---

### Phase 3: 台本生成（太陽スキル）

**ステップ1: タイトル生成**
- スキル: `taiyo-style-headline`
- 入力: Phase 1の収集情報
- 出力: 魅力的なタイトル（10候補）

**ステップ2: 台本生成**
- スキル: `taiyo-style-vsl` + `taiyo-rewriter`
- 入力:
  - 収集情報
  - 選択したテンプレート
  - 選択したタイトル
- 出力: 4-7分の台本（1,200-2,000文字）

---

### Phase 4: 品質チェック

**ステップ1: 日本語読み方チェック（1回目）**
- 難読漢字検出
- 数字読み検証
- 英単語カタカナ確認

**ステップ2: 自動修正**
- 難読漢字 → ひらがな
- 数字 → text_preprocessor適用
- 英単語 → カタカナ追加

**ステップ3: 日本語読み方チェック（2回目）**
- Claude APIで文脈解析
- 最終確認

**ステップ4: 品質検品**
- 文字数チェック（1,200-2,000字）
- 読み上げ時間チェック（4-7分）
- 太陽スコアチェック（70点以上）

---

### Phase 5: Fish Audio音声生成

**入力**:
- 品質チェック済み台本
- ユーザー指定ボイスID
- 選択した話し方パターン

**話し方パターン例**:
- エネルギッシュ型（speed: 1.1）
- 落ち着き型（speed: 0.9）
- プロフェッショナル型（speed: 1.0）

**出力**:
- 高品質mp3ファイル（4-7分）
