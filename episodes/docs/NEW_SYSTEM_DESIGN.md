## 新しいフロー（全体像）

```
[1] キーワード → グローバルリサーチ（world-research + mega-extractor）
          ↓
[2] 人気配信者分析 → 10種類の台本テンプレート生成
          ↓
[3] 太陽スキル → タイトル生成 + 台本生成（4-7分）
          ↓
[4] 品質チェック → 日本語読み方修正 + 検品（2回）
          ↓
[5] Fish Audio → 指定ボイスID + 話し方パターン適用
```

---

## 実装推奨順序

**最速で価値を出す順序**:
```
Phase 1（リサーチ）
  ↓
Phase 3（台本生成 with 太陽スキル）
  ↓
Phase 4（品質チェック）
  ↓
Phase 5（音声生成強化）
  ↓
Phase 2（配信者分析）← 最後に追加
```

**理由**: Phase 2は最も時間がかかるため、基本フローを先に完成させる
