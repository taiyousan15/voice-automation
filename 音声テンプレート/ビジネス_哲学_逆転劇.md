# ビジネス・哲学・逆転劇 テンプレートガイド

## 対象ジャンル（7ジャンル）
- ビジネスモデル / AIビジネス / 哲学 / 逆転劇

## 使用テンプレート

### T01: ヒーローズジャーニー型（逆転劇向け）
- **スタイル**: taiyo_ok（コピーライティング表現許容）
- **ストーリー構造**: 困難 → 気づき → 変容

| セクション | 文字数 | 役割 |
|-----------|--------|------|
| hook | 150字 | 問題提起・共感 |
| story | 600字 | ヒーローズジャーニー展開 |
| solution | 500字 | 解決策・インサイト |
| cta | 100字 | 行動喚起 |

**プロンプト例**:
> 主人公が困難に直面し、気づきを得て変容する物語として構成。冒頭でリスナーの共感を得る問題提起から始め、ストーリーで引き込み、最後に実践的な教訓を提供。

**心理トリガー**: 社会的証明、好奇心ギャップ、好意
**視聴維持**: オープンループ、パターン中断、ストーリーアーク

---

### T02: 問題解決型（ビジネスモデル・AIビジネス向け）
- **スタイル**: taiyo_ok
- **ストーリー構造**: 問題 → 分析 → 解決

| セクション | 文字数 | 役割 |
|-----------|--------|------|
| problem | 200字 | 問題の明確化 |
| analysis | 500字 | 原因分析と背景 |
| solution | 500字 | 具体的な解決策 |
| action_cta | 150字 | アクション＋CTA |

**プロンプト例**:
> 「こんな悩みありませんか？」と問題を明確化し、原因を分析した上で、具体的な解決策を事例付きで提示。

**心理トリガー**: 損失回避、社会的証明、権威性
**視聴維持**: オープンループ、具体的数字、質問投げかけ

---

### T03: 教育コンテンツ型（哲学・経済学向け）
- **スタイル**: fact_strict（事実厳守・誇大表現禁止）
- **NGワード**: 絶対、確実に、必ず儲かる、誰でも簡単に

| セクション | 文字数 | 役割 |
|-----------|--------|------|
| intro | 150字 | トピック紹介 |
| explanation | 650字 | わかりやすい解説 |
| insight | 350字 | 独自の考察 |
| summary | 200字 | 要約 |

**プロンプト例**:
> 信頼できるデータ・事実に基づき、専門用語は必ず平易な言葉で解説。「〜と言われています」「〜という研究結果があります」のように根拠を示す。
