# 投資・経済・お金 テンプレートガイド

## 対象ジャンル（3ジャンル）
- 株式投資 / 暗号通貨 / FIRE・お金

## 使用テンプレート

### T07: 投資分析型
- **スタイル**: fact_strict（事実厳守・金融NG対応）
- **NGワード**: 絶対儲かる、必ず上がる、元本保証、ノーリスク、確実に利益、今すぐ買え、煽り、爆益
- **ストーリー構造**: トピック → データ分析 → リスク/リターン → 免責

| セクション | 文字数 | 役割 |
|-----------|--------|------|
| topic | 150字 | 分析対象の紹介 |
| data | 550字 | データに基づく分析 |
| risk_return | 350字 | リスクとリターンの両面提示 |
| disclaimer_summary | 300字 | 免責事項＋まとめ |

## 法的制約（CRITICAL）

### 金融商品取引法 準拠
- 断定的判断の提供は**禁止**
- 「〜の可能性があります」「〜というデータがあります」のように記述
- 必ずリスクとリターンの**両面を提示**

### 必須免責事項
> 「投資判断は自己責任でお願いします。この放送は投資助言ではありません。」

### 表現ルール
- OK: 「過去のデータでは〜という傾向があります」
- OK: 「一つの見方として〜と考えることもできます」
- NG: 「この銘柄は必ず上がります」
- NG: 「今すぐ買うべきです」

**心理トリガー**: 権威性、損失回避、一貫性
**視聴維持**: 具体的数字、質問投げかけ、予告
