# コンテンツビジネス・DRM テンプレートガイド

## 対象ジャンル（3ジャンル）
- コンテンツビジネス / DRM / プロダクトローンチ

## 使用テンプレート

### T04: プロダクトローンチ型
- **スタイル**: taiyo_ok（コピーライティング表現許容）
- **ストーリー構造**: 衝撃 → 背景 → 方法 → 証拠

| セクション | 文字数 | 役割 |
|-----------|--------|------|
| hook | 200字 | 衝撃的な事実・結果の提示 |
| story | 450字 | 背景ストーリー |
| method | 450字 | 具体的な方法論・ステップ |
| proof_cta | 250字 | 実績・証拠＋CTA |

**プロンプト例**:
> 冒頭で衝撃的な結果・数字を提示し注意を引く。背景ストーリーで信頼性を構築し、具体的な方法論をステップ形式で紹介。最後に実績を示し、次のアクションを促す。

**心理トリガー**: 希少性、社会的証明、返報性
**視聴維持**: オープンループ、パターン中断、具体的数字

**CTA戦略**: 無料コンテンツ → メルマガ → 商品（3段階ファネル）
